# Decision log

Architecture decision records (ADRs) capture choices that materially constrain the product or implementation. They preserve reasoning when context and contributors change.

## Status values

- **Proposed:** open for review.
- **Accepted:** the current decision.
- **Superseded:** replaced by a later ADR.
- **Rejected:** considered but not adopted.
